## Section A — 1 mark each

**Q1.** [MCQ] `lim_{x→0} (sin 5x)/x = ?`
(A) 1  (B) 5  (C) 0  (D) ∞

**Q2.** [MCQ] `lim_{x→0} (1−cos x)/x² = ?`
(A) 0  (B) 1/2  (C) 1  (D) 2

**Q3.** [MCQ] `lim_{x→∞} (1+1/x)^(3x) = ?`
(A) e  (B) e³  (C) 3e  (D) 3

**Q4.** [MCQ] `f(x) = |x|` at x = 0 is:
(A) differentiable  (B) discontinuous  (C) continuous, not differentiable  (D) none

**Q5.** [MCQ] Derivative of `eˣ · ln x`:
(A) eˣ/x  (B) eˣ ln x  (C) eˣ(ln x + 1/x)  (D) eˣ + 1/x

**Q6.** [NAT] Number of points where `f(x) = |x| + |x−2| + |x+1|` is non-differentiable = `____`

**Q7.** [MCQ] Critical points of `f(x) = x³ − 3x`:
(A) x = 0  (B) x = ±1  (C) x = ±√3  (D) none

**Q8.** [MCQ] Local max of `f(x) = −x² + 6x` is at:
(A) x = 0  (B) x = 3  (C) x = 6  (D) x = 9

**Q9.** [MCQ] By MVT for `f(x) = x²` on `[0, 4]`, c = ?
(A) 1  (B) 2  (C) 3  (D) 4

**Q10.** [MCQ] `∫_0^1 x² dx = ?`
(A) 1/2  (B) 1/3  (C) 1/4  (D) 1

**Q11.** [MCQ] `∫_0^(π/2) cos x dx = ?`
(A) 0  (B) 1  (C) π/2  (D) −1

**Q12.** [MCQ] `Σ_{n=1}^∞ 1/n²` = ?
(A) π/6  (B) π²/6  (C) e  (D) ∞

**Q13.** [MCQ] Sum `1 + 1/3 + 1/9 + 1/27 + … = ?`
(A) 3  (B) 3/2  (C) 2  (D) 4/3

**Q14.** [NAT] `∫_0^1 1/(1+x²) dx = ?` (multiple of π) → coefficient is `____`

**Q15.** [MCQ] Series `Σ 1/n` is:
(A) convergent  (B) absolutely convergent  (C) divergent  (D) conditionally convergent
