# 🧪 Tests Index

All tests are generated alongside the topics they cover.

```
_tests/
├── topic_tests/         ← 30-min, single-topic
├── full_length_tests/   ← 3-hr, full syllabus
└── mock_schedule/       ← (see _plans/mock_test_schedule.md)
```

## Conventions

- File names: `subject_topic_test_NN.md` (e.g., `os_scheduling_test_01.md`).
- Each test file contains:
  - Instructions + time limit + marking scheme.
  - Question paper.
  - Answer key + solutions (collapsed/at end).
  - Score-sheet template.

## Workflow

1. Open the test → start a timer → solve.
2. Score yourself — only after timer stops.
3. Run the **post-test protocol** in [../mock_test_schedule.md](../_plans/mock_test_schedule.md).
4. Log score in [../_progress/performance_tracker.md](../_progress/performance_tracker.md).
5. Add wrong answers to [../_progress/mistakes_log.md](../_progress/mistakes_log.md).

Tests are generated as part of the matching batch (see `batch_tracker.md`).
