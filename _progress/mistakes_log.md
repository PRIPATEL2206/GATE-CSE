# 🐛 Mistakes Log

> The single most valuable file in this repo. Re-read **every Sunday**.

Rule: every wrong / unsure / lucky-guess answer goes here. No exceptions.

---

| Date | Subject | Topic | Question (1 line) | What I did wrong | Correct insight / formula | Pattern tag |
|---|---|---|---|---|---|---|
|      |          |        |                    |                  |                            |             |

---

## Pattern Tags (use consistently)

- `unit-trap` — bytes vs bits, ms vs s
- `edge-case` — empty/zero/single-element
- `formula-misuse` — applied wrong formula
- `misread` — misunderstood question
- `time-out` — got it but too slow
- `careless` — arithmetic / sign / off-by-one
- `concept-gap` — didn't know the concept
- `assumed` — assumed something not stated

## Weekly Audit

1. Count entries per pattern tag.
2. The top tag = next week's focus.
3. If the same *topic* appears 3+ times → schedule a re-do.
