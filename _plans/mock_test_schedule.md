## Post-Test Protocol (mandatory, ≥1.5x test time)

1. **Score** — total + section-wise.
2. **Question audit** — for every wrong/skipped question:
   - Was it a *concept* gap or an *execution* gap?
   - Add to **Mistakes Log** with the pattern.
3. **Time audit** — flag every question that took > target time.
4. **Confidence audit** — was I 100% sure on the right ones? Lucky guesses count as mistakes.
5. Update [_progress/performance_tracker.md](../_progress/performance_tracker.md).
