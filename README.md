# 🎯 GATE CS Preparation Repository

> A complete, AIR-1 oriented, production-grade study system for **GATE Computer Science & Information Technology**.
>
> Built like a top coaching institute — atomic topics, structured notes, PYQs with solutions, 20–50 practice questions per topic, weekly plans, mock schedule, and a tracker.

---

## 🧭 How to Use This Repo

1. Read this README and `_plans/weekly_study_plan.md`.
2. Open `batch_tracker.md` — it lists **all batches** (1 subject + 2–3 topics each).
3. To generate a batch's content, tell the AI:
   ```
   Run Batch X
   ```
   Only that batch will be generated. Tracker auto-updates.
4. After every topic: do PYQs → Practice → Mistakes review → Quick Revision card.
5. Use `_tests/` for topic tests, full-length tests, and the mock schedule.

## 🧱 Per-Topic File Structure (Generation Rule)

Every topic file generated by the AI **must** follow this template:

```markdown
# Topic Name

## 1. Concept Explanation
## 2. Important Points
## 3. Short Notes
## 4. Formulas / Tricks
## 5. PYQs (with solutions)
## 6. Practice Questions (20+)
## 7. Mistakes
## 8. Pattern Recognition
## 9. Quick Revision
```

Constraints:
- Markdown only.
- Exam-pattern focused — no filler theory.
- Beginner → Advanced progression within each section.

## 🚀 Run a Batch

Type the command in chat:
```

```
The AI will:
1. Generate the topic .md files for that batch (full 9-section format).
2. Update `batch_tracker.md` (status, dates, file links).
3. Stop and wait for `Run Batch 2`.
