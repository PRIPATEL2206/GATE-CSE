# Logical Reasoning & Analytical Aptitude

> Subject: General Aptitude — Logical
> GATE weight: **2–3 marks** every year. Series, syllogisms, seating, blood relations, puzzles, statements & assumptions.

---

## 1. Concept Explanation

### 1.1 Number Series

Find the pattern; predict next term.

**Common patterns:**
- Arithmetic: +k.
- Geometric: ×k.
- Squares: 1, 4, 9, 16, 25, …
- Cubes: 1, 8, 27, 64, …
- Fibonacci: 1, 1, 2, 3, 5, 8, …
- Alternating sequences.
- Differences of differences.

### 1.2 Letter Series

Map letters to numbers (A=1, B=2, …, Z=26).

**Common shifts:**
- +n, −n.
- Skip-step.
- Reverse letter pairs.

### 1.3 Coding & Decoding

Letters or words encoded by:
- Shift (Caesar cipher: +3).
- Substitution.
- Reversal.
- Position-based.

**Strategy:** identify pattern from given example.

### 1.4 Blood Relations

Decode family relationships from clues.

**Common terms:**
- Father's brother = uncle.
- Mother's sister = aunt.
- Cousin = uncle's/aunt's child.
- Niece = brother's/sister's daughter.
- Grandfather = father's father.

**Tricks:**
- Draw family tree.
- Use generation symbols.

### 1.5 Direction Sense

Compass: N, S, E, W (and intermediates NE, NW, SE, SW).

**Strategy:**
- Track each turn step by step.
- Use coordinate system: N = +y, E = +x.
- Net displacement via Pythagoras if needed.

### 1.6 Syllogisms

From premises, derive conclusions.

**Form:**
- All A are B.
- Some A are B.
- No A are B.
- Some A are not B.

**Rules:**
- Two universal premises → universal conclusion.
- Two particular premises → no conclusion.
- Negative premises → negative conclusion.

**Example:**
- All mammals are animals.
- All dogs are mammals.
- ∴ All dogs are animals.

### 1.7 Statement & Conclusion

From given statement(s), determine which conclusions follow.

**Types:**
- Definitely follows.
- Probably follows.
- Definitely doesn't follow.

### 1.8 Statement & Assumption

Identify assumptions implicit in the statement.

**Strategy:** ask "what must be true for the statement to make sense?"

### 1.9 Cause & Effect

Determine causation between events.

### 1.10 Course of Action

Given a problem, identify proper actions.

### 1.11 Seating Arrangement

| Type | Description |
|---|---|
| Linear | One row, facing same/opposite |
| Circular | Around a table |
| Square / Rectangle | Specific positions |

**Strategy:**
1. Draw arrangement.
2. Mark fixed positions.
3. Apply constraints.
4. Iterate.

### 1.12 Circular Arrangement

For n people around table: (n−1)! arrangements (rotation symmetry).

If facing direction matters: 2·(n−1)!.

### 1.13 Puzzles

Common types:
- People + attributes (cars, jobs, houses).
- Schedules.
- Mappings.

**Strategy:** matrix / grid; cross out impossibilities.

### 1.14 Cubes & Dice

| Type | Concept |
|---|---|
| Painted cube cut into smaller | Count by face |
| Dice opposite faces | 1-6, 2-5, 3-4 sum to 7 |
| Number of corners / edges / faces | 8 / 12 / 6 |

**Painted cube formulas (n×n×n cube):**
- 0 faces painted: (n−2)³
- 1 face: 6(n−2)²
- 2 faces: 12(n−2)
- 3 faces: 8 (corners)

### 1.15 Clocks

| Hand | Speed |
|---|---|
| Hour | 360°/12 hr = 0.5°/min |
| Minute | 6°/min |
| Second | 6°/sec |

**Angle between hands** at h:m =
`|30·h − 5.5·m|`

**Hands together:** every 65 5/11 minutes.

### 1.16 Calendars

**Days of week** cycle every 7 days.

**Leap year:** divisible by 4, not 100 unless 400.

**Day calculation:**
- 365 days = 52 weeks + 1 odd day.
- 366 days = 2 odd days.
- 400 years = 0 odd days.

### 1.17 Figural / Pattern Reasoning

| Type | Strategy |
|---|---|
| Series of figures | Identify rotation, reflection, addition |
| Mirror image | Reflect about axis |
| Water reflection | Reflect about horizontal |
| Paper folding | Trace fold + cut |

### 1.18 Statement-Argument

Given statement; choose strong argument(s) supporting/refuting.

**Strong argument:**
- Logically connected.
- Factually plausible.

**Weak argument:**
- Irrelevant.
- Far-fetched.

### 1.19 Decision Making

Given criteria + cases, decide which cases satisfy.

### 1.20 Common GATE Patterns

- Number series.
- Blood relations.
- Direction sense.
- Syllogism (2-3 premises).
- Seating (linear / circular).
- Clock / calendar.
- Puzzle (small attribute matrix).

> **Summary:** Logical reasoning rewards systematic approach. Use diagrams for blood relations, seating, direction. For syllogisms, apply logic rules. For clocks/calendars, memorize formulas.

## 5. PYQs (with solutions)

### Q1. (GATE Logical 2017)
Series: 2, 6, 12, 20, 30, ?
**Solution.** Differences: 4, 6, 8, 10 → next 12 → 30 + 12 = 42.

### Q2. (GATE Logical 2014)
A's father's only daughter is A's:
**Solution.** Sister.

### Q3. (GATE Logical 2018)
Direction: walked 5km E, 3km N, 5km W. Distance from start?
**Solution.** Net: 0 E, 3 N. Distance = 3 km.

### Q4. (GATE Logical 2008)
Code: A=1, B=2, ... CAT = ?
**Solution.** 3-1-20.

### Q5. (GATE Logical 2010)
Syllogism: All cats are animals. Some animals are dogs. Conclusion?
**Solution.** No definite conclusion (some cats may or may not be dogs).

### Q6. (GATE Logical 2015)
6 people seated around circular table. # arrangements:
**Solution.** (6−1)! = 120.

### Q7. (GATE Logical 2013)
Angle between hour and minute at 3:00:
**Solution.** |30·3 − 5.5·0| = 90°.

### Q8. (GATE Logical 2007)
2024 leap year?
**Solution.** Yes (divisible by 4, not 100).

### Q9. (GATE Logical 2003)
Series: 1, 4, 9, 16, ?
**Solution.** 25 (squares).

### Q10. (GATE Logical 2009)
Dice: opposite to 3?
**Solution.** 4 (sum to 7).

### Q11. (GATE Logical 2019)
3×3×3 painted cube: # cubes with 2 faces painted:
**Solution.** 12·(3−2) = 12.

### Q12. (GATE Logical 2020)
A is B's brother. B is C's sister. C is A's:
**Solution.** Sibling.

### Q13. (GATE Logical 2021)
Distance after walking 3km N, 4km E:
**Solution.** √(9+16) = 5 km.

### Q14. (GATE Logical 2016)
Series: 5, 11, 23, 47, 95, ?
**Solution.** ×2 + 1 → 191.

### Q15. (GATE Logical 2011)
Angle at 4:30:
**Solution.** |30·4 − 5.5·30| = |120 − 165| = 45°.

## 7. Mistakes

| # | Trap | How to avoid |
|---|---|---|
| 1 | Series miscounting differences | Check 2nd differences too. |
| 2 | Blood relation gender ambiguity | Use given clues. |
| 3 | Direction without coords | Use coord grid. |
| 4 | Syllogism: undue conclusion | Apply rules strictly. |
| 5 | Circular arrangement = n! | Use (n−1)!. |
| 6 | Clock angle without absolute value | Use \|...\|. |
| 7 | Leap year only ÷4 | Check ÷100, ÷400 too. |
| 8 | Painted cube wrong formula | Match face count. |
| 9 | Dice opposite face wrong | Sum to 7. |
| 10 | Statement assumes too much | Stick to logical inference. |
